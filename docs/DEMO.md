# Demo guide

## 1. Review a service problem

1. Sign in as `service@demo.local`.
2. Open the Northstar Foods / PX-400 case.
3. Click **Run investigation**.
4. Read the report and open its source links.
5. Open **Approvals** to see the suggested work order.

## 2. See an unsafe request get stopped

1. Return to the same case.
2. Click **Try blocked request**.
3. Confirm that the app stops before searching or writing an answer.
4. Open **View run** to see where it stopped.
5. Confirm that no work order suggestion was created.

## 3. Approve the work

1. Sign in as `manager@demo.local`.
2. Open **Approvals** and review the suggested work order.
3. Click **Approve & execute**.
4. Return to the case and confirm that the work order was saved.
